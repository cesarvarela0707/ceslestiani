LUZ CELESTIA V12 — ACTUALIZACIÓN EN RAMA DE PRUEBA

1. Descomprimí el ZIP.
2. En GitHub Desktop, verificá que Current Branch indique prueba.
3. Repository > Show in Explorer.
4. Copiá el CONTENIDO de esta carpeta (no la carpeta misma) al repositorio.
5. Reemplazá los archivos cuando Windows lo solicite. No borres .git.
6. GitHub Desktop > Changes > Commit to prueba > Push origin.
7. Vercel > Deployments > seleccioná el deployment Preview de prueba > Visit.
8. Revisá /en/ y /es/ antes de considerar publicarla.

La rama main y el dominio de producción permanecen intactos hasta que decidas integrarlos.
