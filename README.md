# Luz Celestia — V12 / Celestia Atelier

Evolución cromática y de interacción basada en la V11, preservando su composición y los seis productos.

## Novedades
- Fondo marfil cálido y superficies celestes, con azul petróleo y detalles champagne.
- Logotipo oficial reforzado sobre una placa celeste de contraste.
- Signo SVG original inspirado en cruz y corazón, usado como marcador editorial.
- Tratamiento de superficies, fotografías, botones, botones de idioma y modales.
- Animaciones de entrada y hover discretas; respeta reducción de movimiento.
- Se conserva todo el contenido de los seis productos, modalidades y precios reales.

## Desarrollo y comprobación

```bash
npm run build
npm test
npm run preview
```

## Vercel

Se incluye `vercel.json`. Branch `prueba` para previsualizar sin tocar `main`.
Copiá el CONTENIDO de esta carpeta dentro del repositorio de la rama `prueba`, reemplazando los archivos existentes.
Commit y Push en GitHub Desktop; Vercel creará un Preview Deployment si está habilitado.

Framework `Other`, build `npm run build`, output `dist`. Sin backend ni variables secretas.
